# 找回密码：配置发信邮箱

用户点“忘记密码”后，网站要给他的注册邮箱发一封带 8 位验证码的邮件。网站本身不负责发信，需要你提供一个能发信的邮箱账号。

::: warning 不配就无法找回密码
没配置发信邮箱时，“忘记密码”无法使用。通过 NodeLoc 自动注册的用户也要靠它设置本站密码（解绑 NodeLoc 时需要）。
:::

![配置找回密码发信的四个步骤](/illustrations/password-mail.svg)

## 1. 准备一个发信邮箱

建议**单独准备一个邮箱**专门发验证码，例如 `noreply@你的域名` 或一个新的 Gmail，不要用存有重要邮件的个人邮箱。

确认这个邮箱：

- 开启了 **SMTP** 发信功能；
- 如果服务商要求，已经生成**应用专用密码**（Gmail 的生成方法见 [中继邮箱](/relay-setup.html#_2-生成应用专用密码)）。

这里的发信邮箱和中继收信账号是两回事，可以是同一个邮箱，但配置互不影响。

## 2. 在后台填写

打开 **管理后台 → 系统配置 → 密码找回发信**（只有超级管理员能修改）：

| 后台字段 | 填什么 | Gmail 示例 |
| --- | --- | --- |
| 主机 | 服务商的 SMTP 服务器域名 | `smtp.gmail.com` |
| 加密端口 | 只能选 **465** 或 **587**，都强制加密 | `465` |
| 发件邮箱 | 收件人看到的发件地址 | `yourname@gmail.com` |
| 登录账号 | 通常是完整邮箱地址 | `yourname@gmail.com` |
| 密码或应用密码 | 服务商要求应用密码时，填应用密码 | 16 位应用专用密码 |

其他常见服务商的 SMTP 地址和端口，请以服务商帮助页为准。

::: tip 网站对发信做的安全限制
- 只连接公网 IPv4 地址上的 SMTP 服务器，不能填内网地址或 IP；
- 强制 TLS 加密，并校验对方证书；证书不正确会直接发送失败；
- 密码加密保存，保存后不再显示，以后留空表示保持不变。
:::

## 3. 开启并保存

勾选 **启用密码找回邮件**，点击 **保存发信配置**。

保存成功只代表格式正确，**不代表真的能发出去**。一定要做下一步。

## 4. 自己走一遍

1. 用浏览器无痕窗口打开登录页，点 **忘记密码**；
2. 输入一个你能收信的测试账户邮箱，完成人机验证；
3. 检查收件箱和垃圾箱，看是否收到 8 位验证码；
4. 输入验证码并设置新密码，用新密码登录。

## 用户找回密码时会发生什么

- 页面**不会**提示这个邮箱是否注册过，防止被人探测账户；
- 验证码 10 分钟内有效，同一个验证码最多试错 5 次；
- 发送有频率限制，按账户、IP 和全站分别计算，频繁请求需要等一会儿；
- 重置成功后，这个账户**所有已登录的设备都会退出**；
- 如果账户绑定过 NodeLoc，重置密码时会**自动解除 NodeLoc 绑定**，需要的话重新绑定即可。这是为了防止别人先用你的邮箱注册 NodeLoc 再登录本站。

## 收不到验证码怎么办

::: details 排查顺序
1. 先看用户的垃圾箱；
2. 确认后台已勾选“启用密码找回邮件”；
3. 确认端口是 465 或 587，账号和应用密码正确；
4. 确认人机验证（Turnstile）已配置好，找回密码需要先通过它，见 [人机验证](/turnstile.html)；
5. 查看服务器上应用容器的日志，找发信相关的报错。
:::
