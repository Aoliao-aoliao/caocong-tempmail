# 后台功能说明

按后台左侧菜单逐个说明每个页面是做什么的、常用操作有哪些、哪些地方要小心。第一次配置的顺序请先看 [第一次进入后台](/admin.html)。

后台地址：`https://你的域名/admin/`

## 菜单一览

| 菜单 | 用途 | 常用操作 |
| --- | --- | --- |
| 运营概览 | 用户、邮箱、邮件、订单的整体数据和服务状态 | 看今天新增、检查服务是否正常 |
| 用户管理 | 所有注册用户 | 改状态、改角色、调整积分、开通或取消会员 |
| 邮箱管理 | 所有用户和访客的邮箱 | 暂停收信、立即到期、停用并隐藏、永久删除 |
| 邮件管理 | 所有收到的邮件 | 处理待检查、已隔离的风险邮件 |
| 域名管理 | 收信域名 | 添加域名、检测 MX、设置类型、审核私有域名 |
| 中继邮箱 | Gmail / Outlook 收信账号 | 见 [中继邮箱](/relay-setup.html) |
| 充值订单 | 用户的充值记录 | 核对付款状态 |
| 积分流水 | 每一笔积分增减 | 对账、排查积分问题 |
| 充值配置 | 充值档位、支付渠道 | 见 [支付与充值配置](/payments.html) |
| 会员管理 | 会员套餐和会员用户 | 设置会员价格、时长、折扣 |
| OpenAPI | 用户的 API 密钥和调用限额 | 停用密钥、调整限额 |
| 人机验证 | Cloudflare Turnstile | 见 [人机验证](/turnstile.html) |
| 系统配置 | 邮箱生命周期、申请档位、积分与安全、版本更新、发信、Telegram、NodeLoc 登录 | 见下方 |
| 审计日志 | 管理员和用户的重要操作记录 | 排查谁在什么时候做了什么 |

## 管理员和超级管理员

后台有两种管理身份：

| 能做的事 | 管理员 | 超级管理员 |
| --- | :---: | :---: |
| 查看后台、管理用户状态、调整积分、开通会员 | ✅ | ✅ |
| 管理邮箱、邮件、域名、中继账号的检测与启用 | ✅ | ✅ |
| 修改其他人的角色、管理超级管理员 | — | ✅ |
| 永久删除邮箱 | — | ✅ |
| 修改人机验证、发信邮箱、Telegram、NodeLoc 登录、微软应用、支付商户配置 | — | ✅ |
| 修改审计日志保留期、清空审计日志 | — | ✅ |

::: warning 谨慎分配管理员
普通管理员也能给任何人（包括自己）调整积分。只把管理员权限给你信任的人。
:::

## 用户管理

- **账户状态**有“正常 / 限制 / 停用”三种。目前“限制”和“停用”的效果**相同**：都无法登录，也无法使用 OpenAPI。想封禁账户时直接选“停用”即可。
- **调整积分**必须填写原因，会记入积分流水和审计日志。积分不能扣成负数。
- **开通会员**：如果用户已经是会员，新开通的时长会在原到期时间上**累加**，不会作废剩余天数。
- **取消会员**：立即结束会员，**不退积分**。

## 域名管理

![五种域名的使用范围](/illustrations/domain-kinds.svg)

| 类型 | 谁能用 | 怎么来的 |
| --- | --- | --- |
| 免费 | 所有人，包括访客 | 管理员添加 |
| 登录用户 | 注册登录的用户 | 管理员添加 |
| 会员 | 有效会员 | 管理员添加 |
| 私有 | 只有所属用户本人 | 会员在用户端添加，管理员审核 |
| 中继 | 按中继账号分配 | 在“中继邮箱”里自动生成，不能在这里改 |

### 添加自己的收信域名

1. 先按 [域名与收信](/mail.html) 配好 MX 和 A 记录；
2. 在 **域名管理** 输入域名，选择类型，点 **添加域名**；
3. 点检测，MX 状态正常后才能启用。

### 审核私有域名

会员添加的私有域名会显示为“待审核”。批准前请**另外确认这个域名确实属于该用户**，例如让对方在域名上加一条你指定的 TXT 记录。

::: danger 不要只看 MX
MX 指向本站并不能证明域名属于谁。如果把别人的域名批准给了错误的用户，这个用户就能收到该域名的所有邮件。
:::

会员过期后，已经批准的私有域名仍然可以继续使用；只有“添加新的私有域名”需要有效会员。

## 邮箱管理

| 操作 | 效果 | 能恢复吗 |
| --- | --- | --- |
| 暂停收信 | 暂时不收新邮件 | 可以恢复 |
| 停用并隐藏 | 用户端看不到，暂停使用 | 可以恢复 |
| 立即到期并清理 | 马上结束有效期，按到期规则清理邮件和附件 | 用户可以召回地址，但旧邮件不恢复 |
| 永久删除（超级管理员） | 删除邮箱、全部邮件和附件 | **不能恢复，也不能召回** |

永久删除中继邮箱时，如果开启了中继“到期清理”，Gmail / Outlook 里对应的原邮件也会被移入垃圾箱。

## 邮件管理

带有可疑附件（例如可执行文件、脚本）的邮件会被标记为 **待检查**，暂时不显示给用户。你可以检查后标记为 **安全**（用户可见），或 **隔离**（继续隐藏）。

## 系统配置

| 标签 | 内容 |
| --- | --- |
| 邮箱与生命周期 | 免费邮箱有效时长、每个用户同时有效的邮箱上限等 |
| 申请档位 | 用户申请邮箱时能选的时长和价格 |
| 积分与安全 | 注册赠送积分、创建邮箱前人机验证开关、OpenAPI 限流等 |
| 版本更新 | 查看是否有新版本，详见 [更新与恢复](/upgrading.html) |
| 密码找回发信 | 见 [找回密码](/password-mail.html) |
| Telegram 绑定 | 见 [Telegram 绑定](/telegram.html) |
| NodeLoc 登录 | 见 [NodeLoc 登录与绑定](/nodeloc-login.html) |

后三个标签只有超级管理员能看到。

## 审计日志

- 默认保留 **30 天**，超级管理员可以改成最多 3650 天。想事后追查管理员操作，建议调大；
- 超过保留期的日志每天自动清理。清理不会影响订单、积分流水和防重复扣费记录；
- 超级管理员可以“清空全部”，清空这个动作本身会留下记录。

## 数据核对看哪里

| 想确认的事 | 看哪里 |
| --- | --- |
| 用户付款到账没有 | 充值订单的状态 + 积分流水里的充值记录 |
| 积分为什么变了 | 积分流水 |
| 谁改了配置或给人加了积分 | 审计日志 |

不要直接改数据库表来“修数据”，也不要手动把订单改成已支付来代替真实的到账检查。
