# 验证范围

验证任务只使用隔离测试环境。作者自用站的部署是单独任务，仅在官方仓库主分支、检查成功、部署开关开启及 production 环境授权后执行；其他安装者不会因此被更新。文档工作流发布静态文档和公开版本公告。

- Astro 类型诊断、生产构建、安装工具离线回归和依赖审计。
- 独立 MySQL 8 服务，仅通过 `127.0.0.1` 使用 `nodemail_ci` 测试库，并要求 `NODEMAIL_ISOLATED_TESTS=1` 与 `NODEMAIL_DISTRIBUTION_FRESH_TEST=1`。
- 空库初始化、并发管理员创建、已有数据保留、迁移摘要和主密钥变更拒绝。
- 从本仓库构建真实容器，验证登录、会话、请求来源、管理接口权限、域名校验、SMTP 握手与保留数据的镜像替换。
- 更新公告使用模拟响应，不向公告服务提交业务数据；SMTP 仅验证连接，不发送真实邮件。

真实第三方邮箱收信、付款、OAuth 授权或 Telegram 绑定需要安装者在自己的环境另行验证。通过构建和隔离测试不等于所有外部平台在所有地区始终可用。

测试状态以本仓库当前提交的 Actions 结果为准。当前测试不覆盖尚未编写的后续数据库迁移。
