# 用户使用指南

这一页写给**使用网站的普通用户**，站长也可以把它转给自己的用户。下文的菜单名称以网站左侧的用户中心菜单为准。

![用户从注册到收信的流程](/illustrations/user-journey.svg)

## 不注册能用吗？

可以。没登录的访客可以在首页申请**免费邮箱**，也可以申请主流邮箱（Gmail 等）地址，每次申请都要先过一次人机验证。

访客邮箱有效期较短（默认 60 分钟），只保存在当前浏览器里：换浏览器、清理 Cookie 后就找不回来了。想长期管理邮箱、续期或召回，请注册账户。

## 注册与登录

- **邮箱注册**：填写邮箱和密码，完成人机验证即可。新用户会获得站长设置的注册赠送积分。
- **NodeLoc 登录**：如果站长开启了，登录页会有 **使用 NodeLoc 登录** 按钮。没有本站账户时会自动注册；邮箱已经注册过的，请先用邮箱密码登录，再到用户中心绑定。详见 [NodeLoc 登录与绑定](/nodeloc-login.html)。
- **忘记密码**：登录页点“忘记密码”，邮箱会收到 8 位验证码，10 分钟内有效。重置后所有设备会退出登录；绑定过 NodeLoc 的需要重新绑定。

## 用户中心菜单

| 菜单 | 用来做什么 |
| --- | --- |
| 个人空间 | 账户概览、积分、会员状态、各类绑定 |
| 临时邮箱 | 用站长提供的域名申请邮箱 |
| 主流邮箱 | 申请 Gmail / Outlook 等主流后缀的中继地址 |
| 地址生成 | 生成用于填表测试的示例地址和身份信息 |
| 邮箱列表 | 管理自己所有的邮箱：复制、续期、召回、进入收信 |
| 邮件列表 | 查看所有邮箱收到的邮件 |
| 域名列表 | 会员添加和查看自己的私有域名 |
| 资金流水 | 积分的每一笔增加和扣减 |

## 申请邮箱

### 临时邮箱

1. 打开 **临时邮箱**；
2. 选择一个域名后缀。不同后缀的使用范围不同：

| 后缀类型 | 谁能用 |
| --- | --- |
| 免费域名 | 所有人，包括访客 |
| 登录用户域名 | 注册并登录后可用 |
| 会员域名 | 有效会员可用 |
| 私有域名 | 只有添加它的会员本人可用 |

3. 填写想要的地址前缀，或者随机生成；
4. 选择有效时长。时长越长，消耗的积分越多；会员享受套餐折扣；
5. 确认积分后创建。

### 主流邮箱

打开 **主流邮箱**，选择 Gmail 等后缀，系统会分配一个形如 `name+a1b2c3@gmail.com` 的地址。发到这个地址的邮件会显示在网站上。

主流邮箱的邮件是网站**定时去取**的，通常要等一小会儿，不是秒到。

## 收信

- 在 **邮箱列表** 里点 **进入收信**，查看某一个邮箱的邮件；
- 在 **邮件列表** 里查看所有邮箱的邮件。

带有可疑附件（例如可执行文件）的邮件可能会被系统拦下待检查，暂时不会显示，这是为了保护你的电脑安全。

## 续期和召回

在 **邮箱列表** 的“到期时间”一栏：

| 按钮 | 什么时候出现 | 效果 |
| --- | --- | --- |
| **续期** | 邮箱还没过期 | 在当前到期时间后面**顺延**，已有邮件都保留 |
| **召回** | 邮箱已经过期 | 把这个地址重新找回来，**从现在开始重新计时**；过期时已清理的旧邮件**不会恢复** |

两者都要消耗积分，按页面上的时长档位收费。会员专属域名的邮箱，只有会员能召回。

::: tip 重要的邮件请及时保存
这是临时邮箱，到期后邮件会被清理，召回也找不回来。需要长期保留的内容请自己另存。
:::

## 积分与充值

- 申请邮箱、续期、召回、开通会员都用**积分**支付；
- 积分不够时，点 **积分充值**，选择站长开放的付款方式（例如 NodeLoc 能量或 USDT）；
- 付款后以 **资金流水** 里的到账记录为准。支付页面跳回“成功”不等于已经到账，稍等片刻再刷新。

## 会员

点顶部的 **开通会员**，选择会员时长并用积分支付。会员可以享受：

- 邮箱创建、召回和续期的套餐折扣；
- 使用 OpenAPI 接口；
- 申请和召回会员专属域名的邮箱；
- 绑定自己的私有域名。

会员到期前再次购买，时长会在原到期时间上**累加**，不会浪费剩余天数。

## 私有域名（会员）

想用自己的域名收信，例如 `me@你的域名.com`：

1. 打开 **域名列表**，添加你的根域名；
2. 到你的域名服务商，把 MX 记录指向站长提供的收信服务器（具体值请问站长）；
3. 等站长核实这个域名确实属于你，审核通过后状态变为“已启用”；
4. 回到 **临时邮箱**，就能选这个域名申请任意前缀的地址，只有你自己能用。

域名审核前，站长需要确认你确实拥有该域名，只把 MX 指向本站并不能自动通过。

## OpenAPI（会员）

会员可以用程序自动申请邮箱、读取邮件：

1. 在 **个人空间** 找到 **API Key**。完整密钥只在生成或重置时显示一次，忘了就点“重置”换一个新的；
2. 点用户中心顶部的 **OpenAPI** 按钮，查看接口说明；
3. 密钥相当于账户密码，不要发给别人或写进公开代码。

会员到期后，接口会提示需要开通会员。

## 绑定第三方账号

在 **个人空间** 里可以：

- **绑定 NodeLoc**：以后可以用 NodeLoc 一键登录。解绑需要输入本站密码；
- **绑定 Telegram**：目前只完成账号绑定，**不推送邮件**，也不能用来登录。每个 Telegram 账号只能绑定一个网站账户。
