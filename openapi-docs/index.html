POST/openapi/v1/mailbox/create.cgi

创建邮箱

创建一个新的收信邮箱；domainId 留空时，从公共域名和登录域名中随机选择。

请求字段

字段类型是否必填说明
prefixstring否5–32 位邮箱前缀，仅支持小写字母、数字、点、下划线和横线；留空时随机生成
domainIdlong否可选的收信域名 ID；留空时从公共域名和登录域名中随机选择
durationHoursinteger否有效时长；留空时默认为 1 小时，必须匹配可用套餐
requestIduuid否UUID v4 幂等标识；也可通过 Idempotency-Key 请求头传递，安全重试时不会重复创建或扣分

成功响应数据

字段类型是否必填说明
idlong是邮箱 ID
emailstring是完整邮箱地址
receivedCountlong是累计收信数
expiresAtdatetime是到期时间
guestboolean是是否为游客邮箱；OpenAPI 创建时固定为 false

响应示例

{"code":0,"msg":"操作成功","data":{"id":128,"email":"demo@example.invalid","receivedCount":0,"expiresAt":"2026-09-03T12:00:00.000Z","guest":false}}
GET/openapi/v1/domain/list.cgi

可用域名列表

查询当前 API 用户可使用的全部域名：公共域名、登录域名、会员域名和当前用户自己的私有域名。权限条件直接在数据库查询中生效。

成功响应数据

字段类型是否必填说明
idlong是可在创建邮箱时作为 domainId 提交的域名 ID
domainstring是收信域名
typeinteger是域名类型：0 公共、1 登录、2 会员、3 私有
ownerIdlong是域名所属用户 ID；系统域名为 0
mailboxCountlong是该域名下未删除的邮箱总数
mailboxOccupylong是该域名下当前有效的邮箱数
mailCountlong是该域名累计收信数
stateinteger是域名状态；列表仅返回状态为 0 的可用域名
createdAtdatetime是创建时间（UTC、ISO 8601）
updatedAtdatetime是更新时间（UTC、ISO 8601）

响应示例

{"code":0,"msg":"操作成功","data":[{"id":1,"domain":"example.invalid","type":0,"ownerId":0,"mailboxOccupy":3,"mailboxCount":8,"mailCount":12,"state":0,"createdAt":"2026-09-01T10:00:00.000Z","updatedAt":"2026-09-04T10:00:00.000Z"}]}
POST/openapi/v1/tools/us_address/generate.cgi

随机美国地址

按现有 OpenAPI 邮箱创建规则创建临时邮箱，并返回指定州或随机州的公开数据地址与随机身份资料。

请求字段

字段类型是否必填说明
prefixstring否5–32 位邮箱前缀，仅支持小写字母、数字、点、下划线和横线；留空时随机生成
domainIdlong否可选的收信域名 ID；留空时从公共域名和登录域名中随机选择
durationHoursinteger否有效时长；留空时默认为 1 小时，必须匹配可用套餐
stateCodestring否美国州的 USPS 两位代码，例如 CA；留空时从 50 州和华盛顿特区中随机选择
requestIduuid否UUID v4 幂等标识；也可通过 Idempotency-Key 请求头传递

成功响应数据

字段类型是否必填说明
mailboxIdlong是本次真实创建的邮箱记录 ID
emailstring是本次真实创建的临时邮箱地址
mailboxDomainIdlong是已创建邮箱所属的收信域名 ID
firstNamestring是随机生成的名
lastNamestring是随机生成的姓
genderstring是按当前接口语言返回的随机性别
phonestring是按地址所属州随机选择区号，并随机生成交换码与尾号
streetAddressstring是公开数据样本中的完整街道地址
citystring是城市
stateNamestring是州的完整名称
stateCodestring是USPS 两位州代码
zipCodestring是ZIP 邮政编码
latitudedecimal是地址纬度
longitudedecimal是地址经度
fullAddressstring是由街道、城市、州和邮编组成的完整地址

响应示例

{"code":0,"msg":"操作成功","data":{"mailboxId":128,"email":"demo@example.invalid","mailboxDomainId":1,"firstName":"Emily","lastName":"Carter","gender":"女","phone":"+1 (202) 483-7612","streetAddress":"4600 Silver Hill Rd","city":"Washington","stateName":"District of Columbia","stateCode":"DC","zipCode":"20233","latitude":38.8459,"longitude":-76.9274,"fullAddress":"4600 Silver Hill Rd, Washington, DC 20233, United States"}}
POST/openapi/v1/mail/list.cgi

邮件列表

分页查询当前 API 用户的邮件；可通过 mailboxId 筛选单个邮箱，邮件按时间倒序排列，每页 10 条。

请求字段

字段类型是否必填说明
mailboxIdlong/string否当前用户拥有的数字邮箱 ID 或 MB-UUID；不传时查询账户下的全部邮件
pageinteger否页码，从 1 开始，默认为 1
keywordstring否发件人或标题关键词，最长 100 个字符

成功响应数据

字段类型是否必填说明
countinteger是符合条件的总记录数
sizeinteger是每页固定为 10 条
pageinteger是当前页码
totalinteger是总页数
dataarray是邮件摘要数组

data 邮件项

字段类型是否必填说明
idlong是邮件 ID
tostring是收件邮箱地址
messageIdstring/null否邮件 Message-ID；邮件未提供时为 null
fromstring是发件人地址
subjectstring/null否邮件主题；无主题时为 null
receivedAtdatetime是收信时间
readboolean是是否已读
keywordstring/null否从邮件中提取的关键词；未提取到时为 null
keywordDisplaystring/null否用于展示的关键词文本；无内容时为 null

响应示例

{"code":0,"msg":"操作成功","data":{"count":1,"size":10,"page":1,"total":1,"data":[{"id":901,"to":"demo@example.invalid","messageId":"example-message-id","from":"NodeMail <notice@example.invalid>","subject":"您的验证码","receivedAt":"2026-09-02T12:30:00.000Z","read":false,"keyword":"897456","keywordDisplay":"897456"}]}}
POST/openapi/v1/mail/detail.cgi

邮件详情

读取指定邮件的完整内容。

请求字段

字段类型是否必填说明
idlong/string是数字邮件 ID 或 MSG-UUID

成功响应数据

字段类型是否必填说明
idlong是邮件 ID
tostring是收件邮箱地址
messageIdstring/null否邮件 Message-ID；邮件未提供时为 null
fromstring是发件人地址
subjectstring/null否邮件主题；无主题时为 null
receivedAtdatetime是收信时间
textContentstring/null否邮件纯文本正文；无正文时为 null
attachmentsarray是附件数组；无附件时为空数组

attachments 附件项

字段类型是否必填说明
fileNamestring是附件文件名
contentTypestring/null否附件媒体类型；未知时为 null
sizelong是附件大小，单位为字节

响应示例

{"code":0,"msg":"操作成功","data":{"id":901,"to":"demo@example.invalid","messageId":"example-message-id","from":"NodeMail <notice@example.invalid>","subject":"您的验证码","receivedAt":"2026-09-02T12:30:00.000Z","textContent":"您的验证码是 897456。","attachments":[]}}
GET/openapi/v1/user/info.cgi

用户信息

查询当前 API Key 对应的账户信息。

成功响应数据

字段类型是否必填说明
idlong是用户 ID
emailstring是登录邮箱
scoreinteger是当前积分
vipExpiredatetime是当前有效会员的到期时间；无有效会员时接口会返回 -1300
stateinteger是账户状态；成功响应固定为 0（有效）
createdAtdatetime是创建时间（UTC、ISO 8601）
updatedAtdatetime是更新时间（UTC、ISO 8601）

响应示例

{"code":0,"msg":"操作成功","data":{"id":1,"email":"user@example.com","score":50000,"vipExpire":"2026-10-01T00:00:00.000Z","state":0,"createdAt":"2026-08-01T00:00:00.000Z","updatedAt":"2026-09-02T00:00:00.000Z"}}
POST/openapi/v1/mailbox/list.cgi

邮箱列表

分页查询当前账户的邮箱。

请求字段

字段类型是否必填说明
pageinteger否页码，从 1 开始，默认为 1
keywordstring否邮箱地址关键词，最长 100 个字符

成功响应数据

字段类型是否必填说明
countinteger是符合条件的总记录数
sizeinteger是每页固定为 10 条
pageinteger是当前页码
totalinteger是总页数
dataarray是邮箱数组

data 邮箱项

字段类型是否必填说明
idlong是邮箱 ID
domainIdlong是收信域名 ID
emailstring是完整邮箱地址
userIdlong是所属用户 ID
receivedCountlong是累计收信数
expiresAtdatetime/null否到期时间；null 表示长期有效
createdAtdatetime是创建时间
updatedAtdatetime是更新时间
expiredboolean是邮箱是否已过期
expiryTextstring是用于页面展示的到期状态文案
expiryTonestring是状态样式：permanent、warning、healthy 或 expired

响应示例

{"code":0,"msg":"操作成功","data":{"count":1,"size":10,"page":1,"total":1,"data":[{"id":128,"domainId":1,"email":"demo@example.invalid","userId":1,"receivedCount":1,"expiresAt":"2026-09-03T12:00:00.000Z","createdAt":"2026-09-02T12:00:00.000Z","updatedAt":"2026-09-02T12:30:00.000Z","expired":false,"expiryText":"24 小时后到期","expiryTone":"warning"}]}}

通用响应与错误

所有接口均使用统一的 code、msg 和 data 响应结构。

字段类型是否必填说明
codeinteger是0 表示成功，负数表示可识别的业务错误
msgstring是面向调用方的结果说明
dataobject/null否成功时返回的业务数据
